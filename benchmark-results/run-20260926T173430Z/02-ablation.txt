How to read this (plan §5.5):
  * A win is claimed only where 'fused' (or 'fused+calibrated') beats BOTH single-engine
    baselines on the SAME labelled set — that is what these columns show.
  * FP-rate is the visible pain (a clean call pushed into an action); recall is the
    expensive pain in production. Neither is free.
  * Every labelled pair counts, including calls where no detector fired (they are
    true negatives). Dropping them would flatter the FP-rate.
  * 'fused+calibrated' re-applies the currently fitted temperature to the stored
    confidence. If the verdicts were written while a fit was already live, that column
    double-calibrates — run --reset and recollect before comparing it.
  * Small N means noise. Treat a difference of a few points as inconclusive.
